== Description ==

Edmin Boost is a smart admin productivity plugin for WordPress. It provides a foundation for customizing and optimizing the WordPress admin experience.

= Features =

* Admin dashboard with quick status overview
* Settings page to enable or disable the plugin
* Clean, extensible plugin architecture
* Translation-ready with a dedicated text domain

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **Edmin Boost** in the admin sidebar to get started.

== Frequently Asked Questions ==

= What does this plugin do? =

Edmin Boost is a smart admin productivity toolkit. The initial release provides the plugin scaffold, dashboard, and settings page. Additional productivity features can be built on top of this foundation.

= Who can access the plugin settings? =

Only users with the `manage_options` capability (typically Administrators) can access Edmin Boost settings.

# Agency plan

The **Agency** plan is an optional commercial license for freelancers and agencies that deploy EdminBoost across multiple client WordPress sites.

## At a glance

| | Agency |
|---|--------|
| **Price** | $99 / year |
| **Sites** | 10-site license pack |
| **Includes** | Everything in Pro (same full feature set as the WordPress.org build) |

## What's included

Agency includes the same plugin features as Pro and the WordPress.org free build:

- Full Command Center (layout presets, top bar drawer panels, Menu Studio, themes, white label)
- Productivity, Security, and Performance tools
- Settings export and import

Agency adds:

- **10-site annual license pack** from Asphalt Themes
- **Agency priority email support**

The WordPress.org free build already includes every feature above with no in-plugin locks. Agency is a **licensing and support** tier, not a feature unlock.

## When to choose Agency over Pro

Choose Agency if you:

- Manage a portfolio of client WordPress sites
- Need a **10-site license pack** instead of buying Pro per site
- Want agency priority support from Asphalt Themes

Choose Pro if you only need a **1-site license** for one production install.

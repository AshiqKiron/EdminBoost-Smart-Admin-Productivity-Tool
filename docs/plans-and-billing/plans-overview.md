# Plans overview

EdminBoost is available in three tiers: **Free**, **Pro**, and **Agency**.

## WordPress.org build (current)

The free plugin distributed on WordPress.org includes **every Command Center and feature tool** with **no in-plugin license checks, trial limits, or feature locks**.

The in-plugin **Billing** page describes optional commercial licenses for direct support and multi-site licensing from Asphalt Themes. You do not need a paid plan to use any feature in the WordPress.org build.

Paid plans are billed **annually**. Checkout and license activation happen on the EdminBoost pricing page — not inside WordPress.

## Plan summary

| Plan | Price | Sites | Best for |
|------|-------|-------|----------|
| **Free** | $0 / year | Unlimited | Full plugin on unlimited WordPress.org sites |
| **Pro** | $49 / year | 1 site | Optional license + priority support for one production site |
| **Agency** | $99 / year | 10 sites | Optional license pack for client portfolios |

## What differs between plans

| | **Free** | **Pro** | **Agency** |
|---|:---:|:---:|:---:|
| Full Command Center and feature tools | ✓ | ✓ | ✓ |
| In-plugin feature locks | None | None | None |
| Community support (WordPress.org forums) | ✓ | ✓ | ✓ |
| Priority email support from Asphalt Themes | — | ✓ | ✓ |
| Licensed updates outside WordPress.org | — | ✓ | ✓ |
| Site license scope | Unlimited | 1 site | 10 sites |
